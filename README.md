# Hospital Management System

## Overview
A REST-based Hospital Management System developed using Spring Boot and Java 21.

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication
- PostgreSQL
- Maven
- JUnit 5
- Mockito
- Postman

## Modules
- Authentication and Authorization
- Patient Management

## Development Workflow
- `main` – repository documentation and stable releases
- `develop` – integrated development branch
- `feature/*` – individual feature development branches

## Project Status
Currently under development.
